# Atelier R

手元の Radeon RX 9060 XT で、SDXL 系のモデルから画像を作る画面です。名前の R は Radeon の R で、自分専用の工房、という意味です。

開くとノードの画面ではなく、文章を書いて **生成する** を押す画面になります。画像を描く処理そのものは、裏側の ComfyUI が行います。NVIDIA の GPU は載っていないので、AMD の ROCm 10.0 版 PyTorch で動かします。

## プロジェクトの概要

- 左でモデル、LoRA、向き、解像度、枚数を選びます。
- 中央に描きたい内容を書いて生成します。
- できた絵は `ComfyUI/output/` に自動で保存されます。別のフォルダへコピーはしません。
- チェックポイントは 1 つ約 6.6GB あるため、コピーせず、今あるファイルをそのまま読みます。

画面が最初から使っている描き方は次のとおりです。サイズと枚数、シードは画面で変えられます。サンプラー以降は画面では固定です。

| 項目 | 値 |
| --- | --- |
| 最初のサイズ | 768×1344（9:16、縦） |
| 一度に作る枚数 | 1（1〜99 の範囲で変更） |
| サンプラー | Euler a（内部名 euler_ancestral） |
| スケジューラ | normal |
| ステップ | 28 |
| CFG | 5.5 |
| CLIP skip | 2 |
| シード | 毎回ランダム。同じ条件で再生成するときだけ、その絵のシードを使います |

## 使い方

### 1. 開く

エクスプローラーで `start_comfyui.bat` をダブルクリックします。起動すると、ブラウザで次のアドレスが開きます。

```text
http://127.0.0.1:8189
```

すでに開いているときにもう一度バッチを押すと、「Atelier R はすでに開いています」と出て、同じアドレスを開き直します。新しい画面は作りません。

ターミナルから開く場合は、このプロジェクトのフォルダで次を実行します。

```powershell
.\start_comfyui.bat
```

ブラウザが開かないときは、上のアドレスを自分で開いてください。終了するときは、黒い画面を選んで `Ctrl + C` を押します。Atelier R が起動した画像エンジンも、一緒に止まります。最初から別のエンジンが動いていた場合は、そのエンジンは止めません。

起動した黒い画面には、スマホ用のアドレスも出ます。今のこの PC では次のアドレスです。Tailscale の番号は起動のたびに読み直すので、画面に出た方を使ってください。

```text
http://100.86.109.80:8189
```

### スマホから開く

自宅の Wi-Fi の外から開くときは、この PC とスマホの両方で Tailscale をオンにします。この PC で Atelier R が起動していることも必要です。スマホのブラウザで、黒い画面に出た `http://100.` で始まるアドレスを開きます。

このアドレスは Tailscale が付けた IPv4 です。自宅 LAN の `192.168.0.8` とは別の番号です。画像エンジン（8188）は PC の中だけのままなので、スマホが開くのは 8189 の画面だけです。

「フォルダを開く」は、この PC のエクスプローラーを開くボタンです。スマホの画面では出しません。生成した絵は、これまで通りこの PC の `ComfyUI/output/` に保存されます。

### 2. 左で選ぶ

1. **基礎モデル** で次のどれかを選びます。最初は Holy Mix です。
   - Holy Mix（`3_HolyMix_00002_.safetensors`）
   - EstellaXL（`2_EstellaXL.safetensors`）
   - AnimeMix v8（`1_animemixillustrious_v8.safetensors`）
2. **LoRA** で Olivia von Ecclesia を選ぶと、強さのつまみと 4 つの言葉が出ます。強さは 0 から 2 です。言葉をクリックすると、中央の入力欄の後ろに足されます。**すべて使用** で 4 つまとめて足せます。選んだだけでは、文章の先頭には自動で入りません。
   - liv (long blonde wavy hair, emerald eyes)
   - red and black royal dress with gold trim
   - ornate black gauntlets on both arms
   - black chest plate
3. **縦横比** のボタンを押すと、幅と高さがその比率の大きさに変わります。最初は `9:16` です。

   | 比率 | 幅×高さ | 向き |
   | --- | --- | --- |
   | 1:2 | 768×1536 | 縦 |
   | 2:1 | 1536×768 | 横 |
   | 9:16 | 768×1344 | 縦 |
   | 16:9 | 1344×768 | 横 |
   | 2:3 | 832×1216 | 縦 |
   | 3:2 | 1216×832 | 横 |
   | 3:4 | 896×1152 | 縦 |
   | 4:3 | 1152×896 | 横 |
   | 4:5 | 896×1120 | 縦 |
   | 5:4 | 1120×896 | 横 |
   | 1:1 | 1024×1024 | 正方形 |

4. 比率の下にある **縦 / 横** と解像度の一覧で、名前からサイズを入れられます。一覧を選ぶと、その下の数字が向きに合わせて変わります。

   | 名前 | 横 | 縦 |
   | --- | --- | --- |
   | FHD | 1920×1080 | 1080×1920 |
   | WQHD | 2560×1440 | 1440×2560 |
   | 4K | 3840×2160 | 2160×3840 |
   | 8K | 7680×4320 | 4320×7680 |

   幅か高さを自分で変えると **カスタム** になり、解像度の一覧は外れます。数字は 512〜7680、8 の倍数、面積は 8K（7680×4320）までです。長い辺が 1536 を超えるサイズは、いったん長い辺を 1536 にして描き、そのあと指定した大きさまで拡大します。
5. **一度に作る枚数** は、数字を入れるか、入力欄の上下の三角で変えます。1 より小さくも、99 より大きくもできません。幅×高さ×枚数がおよそ 3.6 億画素を超える組み合わせも作れません。8K なら 10 枚までです。

### 3. 中央で生成する

描きたい内容を書いて **生成する** を押します。避けたい内容は、閉じてある欄を開くと編集できます。

待ち時間はプログレスバーで分かります。モデルを読み込んでいる間はバーが動き、描き始めるとステップが進みます。進み具合が 10 分変わらないときは、待ちをやめます。最初の 1 枚はモデルを読み込むので、1 分前後かかることがあります。2 枚目以降は短くなります。

生成は、この PC の画面（`http://127.0.0.1:8189`）と、Tailscale でつながった自分の端末から開いた同じ画面で受け付けます。「フォルダを開く」は、この PC の画面からだけです。Tailscale に入っている他の端末からも、この画面は開けます。外に公開したくなったら、Tailscale の許可で届く端末を絞ってください。

### 4. できた絵を見る

絵は画面に出て、同時に `ComfyUI/output/` へ保存されます。ファイル名は `studio_` で始まります。1 回 **生成する** を押したぶんが、使った文章ごとのまとまりになります。

文章にカーソルを合わせると **プロンプトを再利用** が出ます。押すと、今の入力欄の後ろにカンマで足されます。それだけでは生成は始まりません。

絵をクリックすると、作ったときの条件と保存先のファイル名を確認できます。

- **同じ条件で再生成** は、見ている絵と同じシードで作り直します。
- **保存フォルダを開く** は、`ComfyUI/output/` をエクスプローラーで開きます。
- 暗い余白か × で閉じられます。
- 左右の矢印は、そのまとまりの中だけを順番に回り、最後の次は最初に戻ります。
- 横向きの絵はウィンドウの横幅を使って大きく、縦向きの絵は今までどおりの幅で表示します。

同じ文章、同じシード、同じ設定でもう一度作ると、エンジンが前の絵を返すことがあります。新しい絵が欲しいときは、文章を少し変えてください。

### 5. スマホで見る

画面の幅が狭いときは、並びが変わります。Tailscale でスマホから開いたときも、この並びになります。

- できた絵が画面の主役になり、下に短い入力欄と ↑ ボタンが残ります。
- 入力欄をタップすると、その下にモデル、LoRA、縦横比、解像度、枚数、避けたい内容が開きます。欄の中はスクロールできます。上の暗い余白や、欄の空いている部分、**閉じる** で、入力欄だけをしまいます。
- 絵を開いているあいだ、後ろの一覧はスクロールしません。
- 左上の ←、絵の周りの黒い部分、条件カードの周りの黒い部分をタップすると、絵の画面を閉じます。
- 左下の **i** から、シード、使った文章、モデルを見られます。× を押すと、絵の画面に戻ります。

## 各ファイルの役割

| ファイル / フォルダ | 役割 |
| --- | --- |
| `start_comfyui.bat` | Atelier R を開くバッチです。普段はこれをダブルクリックします。 |
| `start_nodes.bat` | ノードを線でつなぐ画面です。普段は使いません。 |
| `studio/app.py` | 画面のサーバーです。ブラウザと ComfyUI の間を取り持ちます。 |
| `studio/static/` | 画面の HTML、見た目、動きです。 |
| `ComfyUI/` | ComfyUI 本体と、Python 3.13 の仮想環境（`.venv`）です。 |
| `ComfyUI/extra_model_paths.yaml` | モデルの置き場所を ComfyUI に教える設定です。 |
| `ComfyUI/constraints-rocm.txt` | ライブラリを入れ直しても、PyTorch が GPU 非対応の通常版に戻らないようにする指定です。 |
| `ComfyUI/output/` | 生成した画像の保存先です。起動後に作られます。 |
| `workflows/sdxl_olivia.json` | ノード画面用のワークフローです。Atelier R の画面では使いません。 |
| `Lora/chekpoint/` | チェックポイント 3 つです。フォルダ名はもともとこの綴りです。 |
| `Lora/【オリヴィア】....safetensors` | オリヴィア LoRA の実体です。 |
| `models/loras/olivia.safetensors` | 上の LoRA へのリンクです。中身は複製していません。 |
| `Lora/kaggle_olivia_generator.ipynb` | Kaggle 上で同じモデルを比べるためのノートです。この PC では使いません。 |

GitHub に入っているのは、画面のプログラムとこの説明です。チェックポイント、LoRA、ComfyUI 本体は数 GB あるため、リポジトリには入れていません。この PC のフォルダには残っています。

## ノード画面を使うとき

Atelier R を `Ctrl + C` で終了してから、`start_nodes.bat` を実行します。ブラウザで `http://127.0.0.1:8188` を開いてください。Atelier R がポート 8188 を使っているあいだは、ノード画面は起動できません。

## 最初の準備（もう一度入れ直すとき）

普段の起動では、下の作業は不要です。PC を変えたときや、環境を作り直すときだけ実行してください。

この PC の通常の Python は 3.14 です。ComfyUI の AMD 向け PyTorch は **Python 3.13** が必要なので、3.14 では入れないでください。

```powershell
winget install -e --id Python.Python.3.13 --scope user --accept-package-agreements --accept-source-agreements

cd ComfyUI
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ --extra-index-url https://pypi.org/simple "torch[device-gfx1200]==2.13.0+rocm10.0.0" "torchvision[device-gfx1200]==0.28.0+rocm10.0.0" "torchaudio==2.11.0.2+rocm10.0.0"
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -c constraints-rocm.txt --extra-index-url https://stable.repo.amd.com/rocm/whl-next/
```

`device-gfx1200` は RX 9060 XT 用です。別の AMD GPU では、ComfyUI の README にある対応表を見て名前を変えてください。

GPU が認識されているかは、仮想環境で次を実行すると確認できます。

```powershell
cd ComfyUI
.\.venv\Scripts\python.exe -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'GPUなし')"
```

ROCm 版の PyTorch は、AMD GPU も `torch.cuda` という名前で扱います。`True` と `Radeon RX 9060 XT` が出れば成功です。

## アップデート

ComfyUI 本体だけを新しくする場合:

```powershell
cd ComfyUI
git pull
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -c constraints-rocm.txt --extra-index-url https://stable.repo.amd.com/rocm/whl-next/
```

## 困ったとき

- ブラウザが開いてもモデル一覧が空: `ComfyUI/extra_model_paths.yaml` のパスを確認し、Atelier R を終了してから開き直してください。
- `Python の仮想環境が見つかりません`: 「最初の準備」を実行してください。
- 「このサイズと枚数の組み合わせはメモリが足りなくなります」: 枚数を減らすか、解像度を下げてください。8K は 10 枚までです。
- 生成中にメモリ不足で落ちる: 他の重いアプリを閉じてから、枚数と解像度を下げて再実行してください。
- 起動しても GPU 名が出ない: AMD Software（Adrenalin）が最新か確認してください。この環境は Windows 11 と Python 3.13 を前提にしています。
