# Atelier R

手元の Radeon RX 9060 XT で、SDXL 系のモデルから画像を作る画面です。名前の R は Radeon の R で、自分専用の工房、という意味です。

開くとノードの画面ではなく、文章を書いて **生成する** を押す画面になります。画像を描く処理そのものは、裏側の ComfyUI が行います。NVIDIA の GPU は載っていないので、AMD の ROCm 10.0 版 PyTorch で動かします。

## プロジェクトの概要

- 左でモデル、LoRA、向き、解像度、枚数を選びます。
- 中央に描きたい内容を書いて生成します。
- 画面で作った絵は `ComfyUI/output/` に自動で保存されます。Muse が作った絵は `ComfyUI/output/muse/` に分かれます。別の場所へコピーはしません。
- チェックポイントは 1 つ約 6.6GB あるため、コピーせず、今あるファイルをそのまま読みます。

画面が最初から使っている描き方は次のとおりです。サイズと枚数、シードは画面で変えられます。サンプラー以降は画面では固定です。

| 項目 | 値 |
| --- | --- |
| 最初のサイズ | 768×1344（9:16、縦） |
| 一度に作る枚数 | 1（1〜99 の範囲で変更） |
| サンプラー | Euler a（内部名 euler_ancestral） |
| スケジューラ | normal |
| ステップ | 28 |
| CFG | 5.5 |
| CLIP skip | 2 |
| シード | 毎回ランダム。同じ条件で再生成するときだけ、その絵のシードを使います |

## 使い方

### 1. 開く

エクスプローラーで `start_comfyui.bat` をダブルクリックします。起動すると、ブラウザで次のアドレスが開きます。

```text
http://127.0.0.1:8189
```

すでに開いているときにもう一度バッチを押すと、「Atelier R はすでに開いています」と出て、同じアドレスを開き直します。新しい画面は作りません。

ターミナルから開く場合は、このプロジェクトのフォルダで次を実行します。

```powershell
.\start_comfyui.bat
```

ブラウザが開かないときは、上のアドレスを自分で開いてください。終了するときは、黒い画面を選んで `Ctrl + C` を押します。Atelier R が起動した画像エンジンも、一緒に止まります。最初から別のエンジンが動いていた場合は、そのエンジンは止めません。

起動した黒い画面には、スマホ用のアドレスも出ます。今のこの PC では次のアドレスです。Tailscale の番号は起動のたびに読み直すので、画面に出た方を使ってください。

```text
http://100.86.109.80:8189
```

### スマホから開く

自宅の Wi-Fi の外から開くときは、この PC とスマホの両方で Tailscale をオンにします。この PC で Atelier R が起動していることも必要です。スマホのブラウザで、黒い画面に出た `http://100.` で始まるアドレスを開きます。

このアドレスは Tailscale が付けた IPv4 です。自宅 LAN の `192.168.0.8` とは別の番号です。画像エンジン（8188）は PC の中だけのままなので、スマホが開くのは 8189 の画面だけです。

「フォルダを開く」は、この PC のエクスプローラーを開くボタンです。スマホの画面では出しません。生成した絵は、これまで通りこの PC の `ComfyUI/output/` に保存されます。

### Muse から生成する

Muse は画面のボタンを押しません。Atelier R に、合言葉付きの生成口があります。モデル、LoRA、枚数の上限は、画面の **生成する** と同じです。画像エンジン（8188）は PC の中だけのままです。

初めて起動すると、プロジェクトのフォルダに `agent_token.txt` が作られます。中の1行が合言葉です。このファイルは GitHub には入りません。チャットや画面写真に写さないでください。

Tailscale で `tag:agent` が付いている端末（Muse）からは、合言葉なしで生成口を使えます。番号は固定せず、起動中に Tailscale から読み直します。スマホや、この PC の中からの生成口は、これまでどおり合言葉が必要です。`tag:agent` を付けるのは Muse だけにしてください。

Muse 以外が使うときは、スマホと同じ `http://100.` で始まる 8189 に、次の見出しを付けます。

```text
Authorization: Bearer 合言葉
```

入口は4つです。

| 操作 | アドレス |
| --- | --- |
| モデル一覧 | `GET /api/agent/options` |
| 生成を始める | `POST /api/agent/generate` |
| 進み具合 | `GET /api/agent/jobs/返ってきたprompt_id` |
| できた絵 | `GET /api/agent/image?filename=ファイル名` |

生成に送る JSON は、画面が内部で送っているものと同じです。`checkpoint`、`prompt`、`width`、`height`、`count` が基本です。LoRA を使うときは `loras` に `{"id","strength"}` を並べます。1 つだけなら、今までの `lora` と `strength` でも受け付けます。

`mode` を省くと、これまでどおり白紙から描きます。できた絵から続けるときは、`source` に `{"filename","subfolder"}` を入れます。`mode` が `vary` のときは似た絵を3枚、`expand` のときは `pad` に `128`、`256`、`384` のどれかを入れて、外側の背景を描き足します。

Muse が作った絵は `ComfyUI/output/muse/` に保存されます。ファイル名は、画面と同じく `studio_` で始まります。画面の **生成する** で作った絵は、今までどおり `ComfyUI/output/` の直下です。進み具合の `output_dir` も、Muse のときは `muse` フォルダを指します。

この PC の中から試すときは、Atelier R を開いたあと、プロジェクトのフォルダで次を実行します。合言葉はファイルから読むので、コマンドに直接書きません。

```powershell
$token = (Get-Content .\agent_token.txt -Raw).Trim()
$headers = @{ Authorization = "Bearer $token" }
Invoke-RestMethod http://127.0.0.1:8189/api/agent/options -Headers $headers
```

合言葉が無い、または違うときは「合言葉が違います。」と返ります。「フォルダを開く」は、合言葉があってもスマホや Muse からは動きません。

### 2. 左で選ぶ

1. **基礎モデル** は、左に今選んでいる1枚だけ出ます。右上の **切り替え** を押すと、画面が暗くなってサムネイルが一覧になります。押したモデルに切り替わり、窓は閉じます。最初は Holy Mix です。置けるのは SDXL のチェックポイントだけです。フォルダにあるファイルが、そのままカードになります。
2. **LoRA** は、足したものだけが左に残ります。**追加する** を押すと、基礎モデルと同じ暗い窓でサムネイルが出ます。押すと足され、窓は開いたままなので続けて選べます。暗い余白か **閉じる** で戻ります。同時に 5 つまでです。それぞれの強さは 0 から 2 です。言葉をクリックすると、中央の入力欄の後ろに足されます。もう一度同じ言葉を押すと、その言葉だけが入力欄から外れます。手で書いた別の文章は残り、カンマの位置も整います。スマホでは、この言葉を押してもキーボードは出ません。キーボードは入力欄をタップしたときだけ出ます。**すべて使用**、**まとめて入れる**、**この衣装** は、そのまとまりの言葉を一度に足します。全部入っているときにもう一度押すと、そのまとまりだけ外れます。まだ入っていない言葉があるときは、足りない分だけ足します。選んだだけでは、文章の先頭には自動で入りません。最初は Olivia von Ecclesia が 1 つ入っています。オリヴィアだけは、はじめからサムネイルがあります。

   一覧のカードにカーソルを合わせると **サムネ** が出ます。そこから画像と、ダウンロード元のページの URL を保存できます。URLを保存したカードには **詳細** も出て、押すと新しいタブでそのページを開きます。画像がまだないカードは、名前の先頭2文字だけ出ます。スマホでは、カーソルを合わせなくても **サムネ** と **詳細** が見えます。保存した画像は `studio/static/previews/`、URLは `studio/model_cards.json` に残り、どちらも GitHub には入りません。
   - liv (long blonde wavy hair, emerald eyes)
   - red and black royal dress with gold trim
   - ornate black gauntlets on both arms
   - black chest plate

   Super Creek（`super-creek.safetensors`）を足すと、次の言葉が出ます。上の文字列は、このファイルが学習で覚えた呼び方です。下はキャラクター名です。括弧の前の `\` は、括弧が「強調」と読まれないようにするための印なので、そのまま使います。
   - `d4pv95de878c73flsqv0`
   - `super creek \(umamusume\)`

   Elegg（`Elegg_-_Goddess_of_Victory_Nikke_Various_Outfits.safetensors`）を足すと、衣装ごとの言葉が出ます。呼び方は `EleggNK` です。**見た目** は髪と目で、どの衣装でも共通です。衣装の名前の横にある **この衣装** を押すと、呼び方と見た目とその衣装の言葉がまとめて入ります。別の衣装の言葉は入りません。サイトに `whte socks` と `oficial alternate costume` と書いてある綴りは、そのままで残しています。

   Hina Asian Mix v5（`hina_flux2klein4b_asianMix_v5.0-lora.safetensors`）を足すと、写真らしい描写の言葉が出ます。**すべて使用** を押すと、次の6つがまとめて入ります。

   - Hyper-realistic photographic
   - extremely high-resolution details
   - realism pushed to extreme
   - fine texture
   - incredibly lifelike
   - asian woman

   新しい LoRA は、`models/loras` に `.safetensors` を置いてから Atelier R を終了し、開き直すと一覧に出ます。表示名や言葉を別に用意していないファイルは、ファイル名のまま出ます。
3. **縦横比** のボタンを押すと、幅と高さがその比率の大きさに変わります。最初は `9:16` です。

   | 比率 | 幅×高さ | 向き |
   | --- | --- | --- |
   | 1:2 | 768×1536 | 縦 |
   | 2:1 | 1536×768 | 横 |
   | 9:16 | 768×1344 | 縦 |
   | 16:9 | 1344×768 | 横 |
   | 2:3 | 832×1216 | 縦 |
   | 3:2 | 1216×832 | 横 |
   | 3:4 | 896×1152 | 縦 |
   | 4:3 | 1152×896 | 横 |
   | 4:5 | 896×1120 | 縦 |
   | 5:4 | 1120×896 | 横 |
   | 1:1 | 1024×1024 | 正方形 |

4. 比率の下にある **縦 / 横** と解像度の一覧で、名前からサイズを入れられます。一覧を選ぶと、その下の数字が向きに合わせて変わります。

   | 名前 | 横 | 縦 |
   | --- | --- | --- |
   | FHD | 1920×1080 | 1080×1920 |
   | WQHD | 2560×1440 | 1440×2560 |
   | 4K | 3840×2160 | 2160×3840 |
   | 8K | 7680×4320 | 4320×7680 |

   幅か高さを自分で変えると **カスタム** になり、解像度の一覧は外れます。数字は 512〜7680、8 の倍数、面積は 8K（7680×4320）までです。長い辺が 1536 を超えるサイズは、いったん長い辺を 1536 にして描き、そのあと指定した大きさまで拡大します。
5. **一度に作る枚数** は、数字を入れるか、入力欄の上下の三角で変えます。1 より小さくも、99 より大きくもできません。幅×高さ×枚数がおよそ 3.6 億画素を超える組み合わせも作れません。8K なら 10 枚までです。

### LoRA を学習する

画面の一番左にある **LoRA** を押すと、ブラウザの新しいタブで学習の履歴が開きます。生成画面の上には窓を出しません。同じタブがすでにあるときは、そちらへ移ります。学習の画面は、左にパラメータ、右に画像が並びます。**トレーニング** は今までの画像セット、**タスク** は学習の記録、**LoRA** は保存したファイルです。カードを開くと、前の画像と設定を直してもう一度学習できます。各画像の左上は、学習で正方形に切る大きさです。タグは画像の下には出ません。右上の **i** を押すと、大きな絵と前後の画像、その画像のタグ、全部の画像へ足したり外したりするタグが開きます。鉛筆でタグの文言を直し、× で外せます。下の入力欄は、**先頭に追加** で全部の画像の前へ、**末尾に追加** で後ろへ足します。LoRA のタブでは、各カードの上の欄が画面に出す名前です。書き換えて **保存** を押すと、そのカードと生成画面の一覧の名前が変わります。LoRA のファイル自体は書き換えません。その下には今の呼び方が並びます。下の欄に言葉を入れて **登録** を押すと、その入力が1つの呼び方として足されます。カンマが入っていても、1回の登録は1つです。学習で覚えた最初の呼び方は残り、あとから足した呼び方は **×** で外せます。足した呼び方は `studio/lora_triggers.json` に残り、LoRA のファイル自体は書き換えません。これは、生成画面のボタンがプロンプトへ入れる言葉です。モデルが反応する言葉を増やすには、学習画面のトリガーワードを直して、もう一度学習します。保存した LoRA にカーソルを合わせると **創作** が出ます。押すと生成画面に戻り、その LoRA が選ばれています。カード下の半透明の帯は、その LoRA で描いた枚数です。

顔の特徴（FLUX.2 で日本人女性の顔を覚えさせたい場合）は、同じ窓で画像と文章の下準備ができます。学習そのものは、次の対応です。

1. **画風** か **キャラクター** を選びます。名前と、プロンプトに書く **呼び方** を入れます。呼び方は `rstyle` のような短い造語にしてください。普通の英単語だと、元のモデルの意味と混ざります。
2. **基礎モデル** は、あとで絵を描くときに使う SDXL を選びます。
3. **画像を追加** で、5 枚以上入れます。15 枚くらいが扱いやすいです。学習では、中央を正方形に切って覚えます。
4. **タグを自動で付ける** を押します。画像を見て、Danbooru 風のタグを呼び方の後ろに書きます。髪や目を呼び方に覚えさせたいときは、「髪や目の説明は外して、呼び方に覚えさせる」をオンにします。オンはキャラクターでは最初から入っています。画風ではオフのままにすると、人物の特徴はタグ側に残り、画風だけが呼び方に残りやすくなります。
5. タグは、画像の右上の **i** から直します。空の画像があるままでは学習を始められません。
6. **モデル効果プレビューのプロンプト** に、見本の絵で使いたい文章を入れます。呼び方が入っていなければ、自動で前に付きます。
7. **学習を始める** を押すと、進み用の新しいタブが開きます。生成が走っているときは、終わるまで待て、と出ます。学習中は GPU を使うので、生成は待ってください。同時に作れる学習は 1 つです。タブの上の棒が、枚数×繰り返し×エポックの進み具合です。作っている LoRA のカードには、その周のパーセントが出ます。1周終わるたびに LoRA が1つでき、見本の絵がカードと右側の大きな欄に出ます。見本は 768 の正方形、20ステップ、毎回同じ乱数です。
8. 終わったら、残したいカードにチェックを入れます。1つでも複数でも大丈夫です。**保存** を押すと、選んだファイルだけ `models/loras/` に入ります。選ばなかったものは消えます。保存するまでは、いつもの LoRA 一覧には出ません。右上の **トレーニングを停止** で、途中の学習を止められます。
9. 保存したあとは、一覧から追加できます。プロンプトへ呼び方を足して、強さは 0.7 くらいから試してください。

学習中のノイズは、絵を描くときと同じ足し方ではなく、SDXL が覚えてきた DDPM の足し方で加えます。描く用の足し方のまま進めると、1周目は元のモデルが絵を描きますが、2周目から砂嵐になります。見本を描くときだけ、今までどおり Euler を使います。

**繰り返し** は、1周の中で同じ画像を何回見せるかです。**エポック** は、その1周を何回まわすかで、終わった周ごとに候補が 1 つ残ります。エポック 1 なら候補は 1 つ、エポック 5 なら 5 つです。5つのときは、名前のうしろに `_e01` から `_e05` が付きます。20 枚・繰り返し 20・エポック 1 なら、だいたい 30 分から 2 時間です。見本を描く時間は、1周につき数分ほど足されます。エポックを増やすと、その倍数だけ時間がかかります。

顔の特徴を選んだときは、タグではなく短い英語の文章を付けます。最初の 1 回だけ、説明用のモデルを取り込みます。

学習で使う追加のライブラリは、仮想環境に次で入ります。Atelier R を入れ直したときは、ComfyUI の準備のあとに実行してください。

```powershell
.\ComfyUI\.venv\Scripts\python.exe -m pip install "diffusers>=0.43" "onnxruntime>=1.20" -c ComfyUI\constraints-rocm.txt
```

### 3. 中央で生成する

描きたい内容を書いて **生成する** を押します。押して待ちに入ると、中央の入力欄は空になります。PC でもスマホでも同じです。使った文章は、できた絵の一覧と生成条件に残るので、そこからまた使えます。待ちが 10 件で追加できなかったときは、入力欄はそのまま残ります。避けたい内容と追加ワードは、閉じてある欄を開くと編集できます。追加ワードは、入れたい言葉を入力して **登録** を押すと、その入力が1つのボタンになります。カンマが入っていても、1回の登録は1つのまとまりです。ボタンを押すと、描きたい内容の後ろにそのまとまりが足されます。もう一度押すと、その言葉だけ外れます。ボタン右の **×** は、一覧からそのボタンを消します。スマホでは、言葉のボタンを押してもキーボードは出ません。

**ランダム** は、生成はせず、描きたい内容の文章だけを入れ替えます。材料は、`ComfyUI/output/` にある最近の絵（最大36枚）です。絵のファイルの中に、そのとき使った文章が残っています。

- 何枚でも出てくる言葉（人数、キャラクター、髪など）は、好みとして残します。
- 衣装やポーズや背景のように、絵によって変わる言葉は、文章の中で近い位置にある別の言葉と入れ替えます。新しいほうの絵ほど、選ばれやすくなります。
- 過去の文章を、そのままコピーはしません。
- 欄にすでに文章があるときは、それも材料に混ぜます。空のときは、今までの絵だけを見ます。
- 左で選んでいる LoRA の呼び方が入っている絵を優先します。その絵が4枚未満のときは、最近の絵を全部見ます。
- LoRA 専用の呼び方は、左にその LoRA があるときだけ使います。例えば `EleggNK` や `Elegg_Bunny`、オリヴィアの呼び方、学習で付けた呼び方です。今その LoRA を使っていないときは、ランダムの材料から外します。`short hair` や `yellow bikini` のような、LoRA がなくても使える普通の言葉は残します。
- まだ絵が1枚もないときは、追加ワードからいくつか選びます。

スマホの狭い画面では、入力欄の右に **乱** と出ます。欄を開くと **ランダム** に戻ります。押したあとに文章を直してから、**生成する** を押してください。

待ち時間は、生成ボタンの下の列で分かります。横幅が 1500px 以上の広い画面では、その列は画面右端の空きに出ます。絵の上には重なりません。スマホや狭い画面では、これまでどおり画面下に出ます。**生成する** は、絵を描いている途中でも押せます。押したぶんは最大 10 件まで順番待ちになり、GPU は 1 件ずつ描きます。ボタンの下には、いま描いている件の進み具合と、後ろに並んでいる文章が出ます。各行の **中止** は、いま描いている1件を止めます。後ろで待っている行の **取消** は、その1件だけ待ちから外します。止めたあとは、その枠が空くので次を入れられます。失敗した行は **閉じる** で一覧から消せます。11 件目は、どれかが終わるまで追加できません。モデルを読み込んでいる間はバーが動き、描き始めるとステップが進みます。進み具合が 10 分変わらないときは、その 1 件だけ待ちをやめます。最初の 1 枚はモデルを読み込むので、1 分前後かかることがあります。同じモデルの 2 件目以降は短くなります。画面を再読み込みすると、並んでいた一覧は消えます。すでにエンジンへ渡した絵は、そのまま最後まで描かれます。

生成は、この PC の画面（`http://127.0.0.1:8189`）と、Tailscale でつながった自分の端末から開いた同じ画面で受け付けます。「フォルダを開く」は、この PC の画面からだけです。Tailscale に入っている他の端末からも、この画面は開けます。外に公開したくなったら、Tailscale の許可で届く端末を絞ってください。

### 4. できた絵を見る

絵は画面に出て、同時に `ComfyUI/output/` へ保存されます。ファイル名は `studio_` で始まります。1 回 **生成する** を押したぶんが、使った文章ごとのまとまりになります。一覧の1枚は、4枚並んだときと同じ大きさです。1枚だけ作っても、横幅いっぱいに広がりません。

文章にカーソルを合わせると **プロンプトを再利用** が出ます。押すと、今の入力欄の後ろにカンマで足されます。それだけでは生成は始まりません。

絵をクリックすると、作ったときの条件と保存先のファイル名を確認できます。スマホでは、左下の **詳細** を押すとこの欄が開きます。同じまとまりが複数枚あるときは、画面上部の余白に `2/4` のように、今見ている枚数が表示されます。左右に送ると、この数字も変わります。

画面の右上にある **選択** を押すと、一覧の絵を複数選べます。選んだ絵には紫の枠が付きます。右上の **削除** を押すと、画面と `ComfyUI/output/` のファイルの両方から消します。一度に 40 枚までです。消した絵は元に戻せません。**やめる** を押すと、普通の見方に戻ります。PC でもスマホでも、ボタンは画面の右上です。

- **似た絵を3枚作る** は、見ている絵の構図を残して、表情や細部が違う絵を3枚作ります。文章とモデルは同じで、シードだけ新しくします。描き直しの強さは 0.55 です。0 に近いほど元の絵に近く、1 に近いほど別の絵になります。
- **周りに足す幅** と **背景を広げて描く** は、外側の余白だけ背景を描き足します。描いたあと、元の絵を中央へ重ねます。余白は灰色ではなく、今の絵のふちを伸ばして、弱く整えるだけです。そのため直線で切れにくく、今の背景が続きやすくなります。足した部分は少し柔らかくなります。細い窓枠まで新品のように描き足すことは、このモデルではまだ得意ではありません。幅は「少し」「ふつう」「広く」の3つです。描き足しは長い辺 1536 までに収めてから、指定した大きさへ拡大します。すでに 8K に近い絵は、それ以上大きくならないことがあります。
- **同じ条件で再生成** は、見ている絵と同じシードで作り直します。
- **保存フォルダを開く** は、`ComfyUI/output/` をエクスプローラーで開きます。
- 暗い余白か × で閉じられます。
- 左右の矢印は、そのまとまりの中だけを順番に回り、最後の次は最初に戻ります。
- 横向きの絵はウィンドウの横幅を使って大きく、縦向きの絵は今までどおりの幅で表示します。

同じ文章、同じシード、同じ設定でもう一度作ると、エンジンが前の絵を返すことがあります。新しい絵が欲しいときは、文章を少し変えてください。

### 5. スマホで見る

画面の幅が狭いときは、並びが変わります。Tailscale でスマホから開いたときも、この並びになります。

- 文字はスマホが自動で大きくしない大きさです。生成画面、LoRA の一覧、学習の設定は、指で上下に送れます。
- できた絵が画面の主役になり、下に短い入力欄と ↑ ボタンが残ります。
- 入力欄をタップすると、その下にモデル、LoRA、縦横比、解像度、枚数、避けたい内容が開きます。欄の中はスクロールできます。上の暗い余白や、欄の空いている部分、**閉じる** で、入力欄だけをしまいます。
- 絵を開いているあいだ、後ろの一覧はスクロールしません。
- 左上の ←、絵の周りの黒い部分、条件カードの周りの黒い部分をタップすると、絵の画面を閉じます。
- 左下の **i** から、シード、使った文章、モデルを見られます。似た絵を作るボタンと、背景を広げるボタンも、この中にあります。× を押すと、絵の画面に戻ります。

## 毎晩22時に開く

Windows のタスク「Atelier R」が、毎日 22:00 に `start_nightly.bat` を実行します。すでに Atelier R が開いているときは、新しい画面は作りません。

この PC が起動していて、あなたがサインインしている必要があります。スリープ中なら、起こせる場合は起こしてから開きます。電源が切れているときは、22時を過ぎても自動では開きません。

止めるときは、22時に出た黒い画面で `Ctrl + C` を押します。自動起動をやめるときは、次を実行します。

```powershell
Unregister-ScheduledTask -TaskName "Atelier R" -Confirm:$false
```

## 追加ワードを増やす

1. 生成画面の **追加ワード** を開きます。
2. 足したい言葉を、入力欄に1つ書きます。`blue eyes` のように空白が入っていても、`hands on chest, emphasizing cleavage` のようにカンマが入っていても、1回の入力は1つの言葉です。
3. **登録** を押します。その言葉が1つのボタンになります。サーバーを止め直す必要はありません。
4. ボタンを押すと、描きたい内容の後ろに、その言葉がまとめて足されます。もう一度押すと外れます。
5. いらないボタンは、右の **×** で一覧から消せます。描きたい内容にすでに入っている文は、× では消えません。

同じ言葉は、ボタンが1つだけです。1つの言葉は200文字まで、一覧は300個までです。`#` で始まる言葉は登録できません。

ファイルで直すこともできます。`studio/extra_words.txt` を開き、1行に1つの言葉を書きます。`#` で始まる行は説明なので、画面には出ません。保存したあと、ブラウザを更新すると反映されます。

## 最初の準備（もう一度入れ直すとき）

普段の起動では、下の作業は不要です。PC を変えたときや、環境を作り直すときだけ実行してください。

この PC の通常の Python は 3.14 です。ComfyUI の AMD 向け PyTorch は **Python 3.13** が必要なので、3.14 では入れないでください。

```powershell
winget install -e --id Python.Python.3.13 --scope user --accept-package-agreements --accept-source-agreements

cd ComfyUI
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install --index-url https://stable.repo.amd.com/rocm/whl-next/ --extra-index-url https://pypi.org/simple "torch[device-gfx1200]==2.13.0+rocm10.0.0" "torchvision[device-gfx1200]==0.28.0+rocm10.0.0" "torchaudio==2.11.0.2+rocm10.0.0"
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -c constraints-rocm.txt --extra-index-url https://stable.repo.amd.com/rocm/whl-next/
```

`device-gfx1200` は RX 9060 XT 用です。別の AMD GPU では、ComfyUI の README にある対応表を見て名前を変えてください。

GPU が認識されているかは、仮想環境で次を実行すると確認できます。

```powershell
cd ComfyUI
.\.venv\Scripts\python.exe -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'GPUなし')"
```

ROCm 版の PyTorch は、AMD GPU も `torch.cuda` という名前で扱います。`True` と `Radeon RX 9060 XT` が出れば成功です。

## 困ったとき

- ブラウザが開いてもモデル一覧が空: `ComfyUI/extra_model_paths.yaml` のパスを確認し、Atelier R を終了してから開き直してください。
- `Python の仮想環境が見つかりません`: 「最初の準備」を実行してください。
- 「このサイズと枚数の組み合わせはメモリが足りなくなります」: 枚数を減らすか、解像度を下げてください。8K は 10 枚までです。
- 生成中にメモリ不足で落ちる: 他の重いアプリを閉じてから、枚数と解像度を下げて再実行してください。
- 起動しても GPU 名が出ない: AMD Software（Adrenalin）が最新か確認してください。この環境は Windows 11 と Python 3.13 を前提にしています。
